# Horizon Radiation Tomography

Simplified Hawking/Unruh radiation studied through Gaussian quantum-state tomography. We model horizon-induced particle creation as a two-mode squeezed Gaussian state — one mode accessible to an outside observer, one mode hidden beyond the horizon. 
Tracing out the hidden mode leaves the observer with a thermal mixed state. 
We simulate finite, noisy measurements of the accessible mode and reconstruct its covariance matrix, squeezing parameter, particle number, and entanglement entropy, to study how much information about horizon-generated radiation survives partial, noisy observation.
